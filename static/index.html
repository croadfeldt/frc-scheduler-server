Import custom schedule from PDF
EXPERIMENTAL FEATURE
PDF import is unreliable, especially on day-plan / itinerary-style PDFs with merged cells. A known issue: the model can repeat the morning qualification block and miss afternoon quals, ceremonies, or playoffs entirely. Always review the preview carefully, edit the form after applying, and don't trust the times blindly. For reliable imports, use TBA event keys, FIRST FMS export, or paste matches directly.

Upload a qualification schedule PDF. The schedule will be parsed by a self-hosted LLM and shown for review before importing. Best results: PDFs with clear table structure (column headers like Match #, Time, Red 1, etc.). Re-uploading the same file is free (cached).

⚠ LLM extraction can misread digits (8 vs 3, 0 vs 6) and miss surrogate notation. Always review the parsed result before confirming import.
